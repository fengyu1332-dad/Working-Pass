## 📋 当前问题分析

### 现有报告生成模式
目前的报告生成方式是**简单的模板填充**，从`majors`表直接拼接字段：
```python
# 简化版的现有逻辑
preview_content = "【专业概述】\n" + major['overview'] + "\n\n" + \
                 "【雪峰点评（预览）】\n" + major['xuefeng_comment'][:200]
```

### 存在的问题
1. **内容深度不足**：仅展示基础信息，缺乏深度分析
2. **数据质量参差不齐**：部分专业的概述、点评内容过于简单
3. **缺乏结构化分析**：没有系统性的分析框架
4. **AI能力未充分利用**：仅做简单拼接，未发挥大语言模型的优势

## 🤖 各Agent详细设计

### 1. 任务协调Agent (Coordinator Agent)

**职责**：
- 接收报告生成请求
- 分解任务并分发给各子Agent
- 协调各Agent的执行顺序
- 监控执行进度

**输入**：
```python
{
    "major_code": "080901",
    "major_name": "计算机科学与技术",
    "category": "08 工学",
    "priority": "high"  # high/medium/low
}
```

**输出**：
```python
{
    "status": "in_progress",
    "task_id": "task_20260522_001",
    "assigned_agents": [
        "data_collection_agent",
        "deep_analysis_agent",
        "xuefeng_comment_agent",
        "composer_agent",
        "qa_agent"
    ]
}
```

---

### 2. 数据收集Agent (Data Collection Agent)

**职责**：
- 收集基础专业数据（从majors表）
- 补充缺失数据（如课程、就业等）
- 校验数据完整性

**执行流程**：
1. 从`majors`表获取现有数据
2. 检查必填字段是否完整
3. 对缺失字段进行数据增强
4. 构建结构化的数据源

**Prompt示例**：
```python
"""
你是一个专业的数据收集专家。请根据以下信息，补充并完善专业数据。

专业名称：{major_name}
专业代码：{major_code}
所属分类：{category}

现有数据：
{existing_data}

请补充以下缺失信息（如果现有数据已有，则直接使用）：
1. 专业概述（200-300字）
2. 适合人群（100字以内）
3. 就业前景（150-200字）
4. 薪资范围（具体数字）
5. 四年课程安排（分年级列出核心课程）

请以JSON格式返回完整数据。
"""
```

---

### 3. 深度分析Agent (Deep Analysis Agent)

**职责**：
- 进行多维度专业分析
- 生成结构化分析内容
- 提供数据支撑的结论

**分析维度**：
```python
{
    "专业深度分析": {
        "学科定位": "该专业在学科体系中的位置和作用",
        "核心能力培养": "学生需要掌握的核心能力",
        "行业发展趋势": "该专业对应行业的发展趋势",
        "就业市场分析": {
            "需求变化": "近几年的需求变化趋势",
            "主要雇主": "主要的就业单位类型",
            "岗位分布": "主要的就业岗位"
        },
        "职业发展路径": {
            "初级岗位": "刚毕业的典型岗位",
            "中级岗位": "3-5年经验的发展方向",
            "高级岗位": "长期职业发展目标"
        },
        "技能要求": {
            "硬技能": "专业技术技能",
            "软技能": "沟通、协作等能力"
        }
    }
}
```

**Prompt示例**：
```python
"""
你是一个教育和职业发展专家。请对{major_name}专业进行深度分析。

专业基础数据：
{major_data}

请从以下维度进行深度分析：

1. 学科定位（150字）
2. 核心能力培养（200字）
3. 行业发展趋势（200字）
4. 就业市场分析（250字）
5. 职业发展路径（200字）
6. 技能要求（150字）

每个维度都要提供有价值的见解，不要过于空泛。
"""
```

### 4. 雪峰点评Agent (Xuefeng Comment Agent)

**职责**：
- 以张雪峰风格撰写专业点评
- 结合就业数据和实际经验
- 给出切实的报考建议

**张雪峰风格特点**：
- 口语化、接地气
- 直接、不绕弯子
- 结合具体数据
- 给出实际建议
- 略带幽默

**Prompt示例**：
```python
"""
你是张雪峰，一位深受学生喜爱的高考志愿填报专家。请对{major_name}专业进行点评。

专业数据：
{major_data}

请按照以下结构撰写点评：

【先说"痛点"】
1. 这个专业可能面临的问题或挑战
2. 就业、考研等方面的现实情况

【但也有优势】
1. 这个专业的优势和亮点
2. 适合报考的理由

【报考建议】
1. 什么样的学生适合报考
2. 填报志愿时的注意事项

【总结】
一句话总结

要求：
- 用口语化的表达，像和学生聊天一样
- 要真实、接地气，不要假大空
- 可以适当幽默，但不要过度
- 给出的建议要切实可行
- 字数控制在800-1200字
"""
```

### 5. 报告合成Agent (Composer Agent)

**职责**：
- 整合各Agent的输出
- 生成结构化的报告
- 确保报告格式统一

**报告结构**：
```markdown
# {major_name}专业深度分析报告

## 一、专业概述
{overview_content}

## 二、课程安排
{curriculum_content}

## 三、就业前景
{career_content}

## 四、薪资范畴
{salary_content}

## 五、适合人群
{suitable_content}

## 六、顶级院校推荐
{universities_content}

## 七、深度分析
{deep_analysis_content}

## 八、雪峰点评
{xuefeng_comment_content}
```

---

### 6. 质量审核Agent (Quality Assurance Agent)

**职责**：
- 检查报告内容质量
- 验证信息准确性
- 修正格式和语法错误
- 确保一致性

**质量检查清单**：
- [ ] 内容完整性（所有必填部分都有）
- [ ] 信息准确性（与事实相符）
- [ ] 逻辑一致性（各部分内容不矛盾）
- [ ] 语言质量（语法正确、表达清晰）
- [ ] 格式规范（符合统一模板）
- [ ] 字数要求（各部分达到预期长度）

**修正Prompt**：
```python
"""
你是一位专业的内容审核专家。请检查以下报告内容，并进行必要的修正。

报告内容：
{report_content}

请检查：
1. 内容是否完整
2. 信息是否准确
3. 逻辑是否通顺
4. 语言是否流畅
5. 格式是否规范

如果发现问题，请进行修正并返回修正后的完整报告。
如果没有问题，请直接返回原报告。
"""
```

## 💡 报告质量保证体系

### 1. 数据质量保证

**数据来源优先级**：
1. **权威数据源**（教育部、统计局等）
2. **教育部门公开数据**
3. **高校官网信息**
4. **行业报告**
5. **AI生成补充数据**（最低优先级）

**数据验证流程**：
```
原始数据 → 完整性检查 → 准确性验证 → 一致性校验 → 清洗入库
```

### 2. 内容质量保证

**多层审核机制**：
1. **自动审核**（QA Agent）
   - 语法检查
   - 格式检查
   - 内容完整性检查

2. **抽样人工审核**
   - 高优先级专业100%审核
   - 中优先级专业50%审核
   - 低优先级专业10%审核

3. **用户反馈迭代**
   - 收集用户反馈
   - 定期优化报告内容

### 3. 质量评估标准

**评分维度**（每项10分，总分100分）：
- 内容完整性：20分
- 信息准确性：20分
- 深度分析：20分
- 实用性：20分
- 语言表达：10分
- 格式规范：10分

**等级划分**：
- A级（90-100分）：优秀，直接发布
- B级（75-89分）：良好，小幅修正后发布
- C级（60-74分）：合格，需重新生成部分内容
- D级（60分以下）：不合格，重新生成
