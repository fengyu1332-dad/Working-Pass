迁移路径建议：
1️⃣ 先在独立页面验证 Vue 3 组件（当前阶段）
2️⃣ 使用 <script type="module"> 加载 Vue 3 CDN + 组件
3️⃣ 在 index.html 的特定区域用 createApp 挂载
4️⃣ 逐步将原生 JS 逻辑迁移到 Vue 3 组件内
5️⃣ 最终用 Vue Router + Vite 完成全站 SPA 化
<!-- 使用方式 -->
<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script src="/js/vue-components/modal.js"></script>
<script src="/js/vue-components/navbar.js"></script>
<script>
  const app = Vue.createApp({ ... });
  app.component('major-modal', MajorModal);
  app.component('site-navbar', SiteNavbar);
  app.mount('#app');
</script>
